All dictionary entries, Japanese spellings, readings, reading restrictions,
and English sense restrictions are retained. English glosses, their type/
gender qualifiers and sense notes are projected for display. Unused source
metadata and non-English glosses are omitted. An exact Japanese form index
is built locally in the browser worker. This transformation and compression

The pinned release URL, archive SHA256, exact entry/sense counts, dictionary
source date, transformations, package versions, npm integrity values and
all output checksums are in each version's manifest.json and SHA256SUMS.txt.
The source lock is src/lib/japanese-language-source.json in the public source.

Regular update procedure (at least monthly, as required by EDRDG):
1. Review the latest public scriptin/jmdict-simplified release and select the
   complete jmdict-eng archive, never jmdict-eng-common.
2. Update release, URL, member, archive byte count and independently reviewed
   GitHub release SHA256 digest in src/lib/japanese-language-source.json.
3. Bump assetVersion for every dictionary, worker or reading-engine change.
4. Run npm ci, then npm run language:prepare. Preparation checks the locked
   archive digest and full-English/non-common status, retains every entry,
   and writes deterministic compressed assets and provenance. It will refuse
   to replace different content at an existing immutable version URL.
5. Review the generated date, complete entry/sense counts, checksums, notices,
   real readings and lookup behavior. Publish the versioned assets with the
   matching application and legal attribution. Remove unused old releases
   from the deployment when no longer referenced. Do not keep serving an
   outdated data version in lieu of performing the monthly update.

Privacy and limits
Language assets use fixed, versioned, same-origin URLs. No selected word,
cue text, prefix, hash or text-derived shard selector is requested remotely.
Kuromoji data is loaded only on first reading/lookup activation. The complete
English dictionary is loaded only on first word lookup; its exact-form index
exists in a browser worker, not a remote search service. There is no user-text
cache, text logging, sentence translation or AI-generated definition. Unknown
kanji retain their original surface without an invented kana or romaji reading.
Kuromoji/IPADIC is a morphological dictionary, not a guarantee of correct
contextual readings. JMdict is a general dictionary, not a proper-name database.
Reading and dictionary processing never controls native-player playback.
